이번 변경
- StatsBoard: 테두리까지 canvas 하나로 통합, 단일 면, 깊이 검사 유지/쓰기 해제,
  helmet 뒤 렌더 순서 유지, frustum culling 해제, mipmap/anisotropy 4.
  표시 값이 바뀔 때만 texture 업로드. hover 갱신 최대 20 Hz, 평상시 6 Hz.
- StationPicker/PoseGuide/Workshop의 투명 안내선은 depthWrite=false.
- WorkpieceGrab/TrainingUI: 한 프레임 12 cm 초과 이동 시 현재 잡기 취소.
  PhysicalControllers: 위치 12 cm/회전 60도 초과 불연속 시 입력 해제 요구.
  머리/헤드셋 카메라 추적에는 필터를 추가하지 않음.
- WeldBead: 5열 움직이는 단면 대신 25열 고정 표면 격자. 각 셀의 높이/열/
  품질/위상을 누적. 운봉의 실제 좌우 궤적, 방향, 끝점 정지가 형상에 남음.
  실제 표면으로 투영하고 높이 기울기로 법선 계산. 타일 노멀/AO는 약한 디테일만.
  위상은 고정 7 Hz 시간 대신 이동 거리에서 생성. 화면에서 작은 물결 대비 감쇠.
- 중력은 뜨거운 셀 사이의 보존적 이동. 양방향 flux를 모두 구한 뒤 반영하며
  냉각 후 멈춤. 고정 격자여서 인접 행을 서로 접거나 이전 비드를 끌지 않음.
- 갱신된 속성 범위만 GPU 업로드, 잔열 있는 행만 냉각. 기본 320 구간/불꽃 80.
  reset 시 전체 업로드 범위를 남겨 다음 적층 때 예전 GPU 비드가 되살아나지 않음.
- 용융풀은 누적 비드 높이를 따라 올려 반복 패스에서 묻히지 않도록 처리.
- selftest.mjs 기존 단면 폭/중심 검사를 실제 적층 분포 기준으로 수정,
  양쪽 위빙 유지·정지 적층·중력 체적 보존·냉각 고정·초기화 회귀 사례 추가.

앞선 턴 변경도 유지
- index.html/pipe.html/shop.html 모두 shop.js 기반 기초 작업실.
  직선과 파이프 두 작업물 및 상단 선택 버튼. pipe.html은 파이프 선택 시작.
- 기본 하진 8단계: 12→5 반시계, 1→12 과주행 겹침, 시계로 6,
  6→5 겹침, 이후 5↔6 편도 4회. 마지막 아크 해제.
- 기본 철판 기준 90도/철판 쪽 2 mm; 전광판 각도·겨냥 거리 설정 유지.

- 작업 선택 설명판은 작업물 자체의 경계를 기준으로 붙여 천장 배치 문제 수정.
- HTTPS 실행은 npm run serve:vr. npm run serve :vr는 잘못된 호출(HTTP).
