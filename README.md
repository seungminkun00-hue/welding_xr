# MIG 용접 XR 시뮬레이터 — 평판 맞대기 일자 비드

평판 두 장을 맞댄 1G(아래보기) 자세에서 직선 MIG 비드를 놓는 WebXR 트레이너입니다.
빌드 단계 없이 `index.html`의 importmap으로 three.js r160을 CDN에서 불러옵니다.

## 실행

```bash
python -m http.server 8777        # 아무 정적 서버나 가능
# http://127.0.0.1:8777/  열기 (VR은 Quest 브라우저에서 "Enter VR")
```

`?debug=1`을 붙이면 `window.weldDebug`로 `scene / camera / renderer / seam /
guide / bead / hud / session / desktop`에 접근할 수 있습니다. 헤드셋 없이
콘솔에서 값을 바꿔가며 튜닝할 때 씁니다.

## 조작 (데스크톱)

| 키 | 동작 |
|---|---|
| W / S | 진행 · 후퇴 (운봉) |
| A / D | 좌우 이동 (중심 이탈) |
| Shift | 빠른 이동 (재배치용) |
| Q / E | 아크 길이(토치-모재 거리) |
| ↑ / ↓ | 전진각 (push angle) |
| ← / → | 작업각 (work angle) |
| Space | 트리거 (아크 ON) |
| R | 다시 하기 |

VR에서는 컨트롤러가 토치, 트리거가 아크입니다.

## 가이드 구성

모재 위(레퍼런스 ①):

- **노란 점선 영역** — 허용 용접 구역. 비드 폭보다 넉넉히 패딩을 줘서 남은 여유를 보여줍니다.
- **노란 화살표(셰브런)** — 진행 방향. 커서 앞쪽만 흐르고, 비드 끝을 지나서도 계속 이어져
  다음에 가야 할 방향을 가리킵니다.
- **파란 실선** — 아직 용접하지 않은 남은 경로.
- **파란 원** — 토치가 모재와 맞닿는 현재 접점.

토치 위에 떠다니는 HUD(레퍼런스 ②③), 항상 시점을 향해 빌보딩됩니다:

- **깊이 가이드** — 아크 길이(CTWD). 화살표 끝이 가로대에 닿으면 정상, 가로대를 뚫고
  내려가면 너무 가까움, 위로 물러나면 너무 멈.
- **중앙 가이드** — 십자선 위의 점. 가로축 = 심 중심에서의 좌우 이탈, 세로축 = 전진각 오차.
- **속도 가이드** — 빨강/노랑/초록 다이얼. 바늘이 초록이면 적정 운봉 속도.

## 비드

HUD만 보고 끝나지 않도록, 실제로 놓인 비드가 결과물로 남습니다.

- 천천히 가면 넓고 두껍게 쌓이고, 빨리 가면 가늘게 굶습니다 (적층량 ∝ 1/속도).
- 리플 간격은 고정 아크 주파수에서 생기므로 속도가 빠를수록 늘어납니다.
- 심에서 벗어나면 비드도 토치를 따라 끌려갑니다.
- 자세가 나쁠수록 스패터가 많아지고 비드 색이 어두워집니다.

## 채점

`WeldSession`이 아크가 켜진 시간 중 각 축이 허용 오차 안에 있던 비율을 누적합니다.
총점 = 깊이 30% + 중앙 30% + 속도 25% + 적층률 15%.

기준값(`src/WeldSession.js`에서 조정):

| 항목 | 기준 | 허용 |
|---|---|---|
| 아크 길이 | 10 mm | ±4 mm |
| 중심 이탈 | 0 mm | ±5 mm |
| 전진각 | 15° push | ±18° |
| 운봉 속도 | 10 mm/s | ±6 mm/s |

## 파일

| 경로 | 내용 |
|---|---|
| `main.js` | 씬·모재·토치·입력·메인 루프 |
| `src/WeldSeam.js` | 직선 심 좌표계 (진행 / 법선 / 횡방향) |
| `src/LinearGuide.js` | 모재 위 가이드 (영역·화살표·중심선·접점 원) |
| `src/TorchHud.js` | 토치 위 3종 게이지 (캔버스 → 빌보드 쿼드) |
| `src/WeldBead.js` | 비드 적층 · 용융풀 · 스파크 |
| `src/WeldSession.js` | 측정·판정·채점 |
| `legacy/` | 이전 원형 파이프 조인트 가이드 (참고용, 미사용) |

## 테스트

```bash
npm test
```
