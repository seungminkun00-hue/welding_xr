MIG 용접 XR — 평판 맞대기 일자 비드

두 장의 평판을 맞댄 1G 자세, 앞쪽에서 뒤쪽으로 직선 운봉합니다.

  • 운봉: W/S = 진행·후퇴 · A/D = 좌우(중심 이탈) · Shift = 빠른 이동
  • 아크길이: Q/E = 토치를 모재에서 띄우거나 붙이기
  • 각도: ↑/↓ = 전진각(push) · ←/→ = 작업각(roll)
  • 트리거: Space(데스크톱) / VR 컨트롤러 트리거
  • 다시: R

노란 점선 = 허용 용접 영역(비드 폭만큼 여유) · 노란 화살표 = 진행 방향 · 파란 실선 = 아직 남은 경로 · 파란 원 = 현재 접점

토치 위 HUD — 깊이: 화살표가 가로대에 닿으면 정상, 뚫고 내려가면 너무 가까움 · 중앙: 점이 십자 중심이면 정렬 (가로축 = 좌우 이탈, 세로축 = 전진각) · 속도: 바늘이 초록 구간이면 적정 운봉 속도
